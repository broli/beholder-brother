# Development Research & Internal Notes

This directory holds internal developer artifacts, architecture decision records (ADRs), benchmarking notes, and technical research.

> [!NOTE]
> This folder is strictly for engineering notes and research scratchpads—**not** user-facing program documentation or API manuals.

## Organization
- `adr/`: Architecture Decision Records documenting key design decisions and trade-offs.
- `research/`: Crate evaluations, performance benchmarks, and exploration spikes.
